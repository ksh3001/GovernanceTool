# Transparency note: Support Chatbot

## Telling customers it is an AI
Every conversation starts with a message saying that the assistant is an AI and
not a human. The message is defined in `disclosure.py` and is shown before the
customer can type.

## Reaching a person
Customers can type "agent", "human" or "person" at any time to be handed over to a
support colleague.

## Content
The chatbot produces text answers in a chat window only. It does not create images,
audio or video.
